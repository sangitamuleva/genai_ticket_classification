AI Ticket Classification Backend 🚀

An AI-powered ticket classification backend built using FastAPI, MySQL, and Google Gemini.
The system automatically classifies support tickets by category and priority using Generative AI.

This project is designed as a backend portfolio project demonstrating real-world backend + GenAI integration.


---

✨ Features

🔐 JWT Authentication (Login / Register)

🎫 Ticket Creation & Management

🤖 AI-based Ticket Classification (Category + Priority)

⚡ FastAPI with Swagger (OpenAPI)

🗄️ MySQL Database with SQLAlchemy ORM

🧠 Google Gemini Integration (Free Tier)

🧩 Clean Project Structure (routers, services, schemas)



---

🏗️ Tech Stack

Layer	Technology

Backend	FastAPI (Python)
Database	MySQL
ORM	SQLAlchemy
Authentication	JWT (OAuth2 Password Flow)
AI Model	Google Gemini (google-generativeai)
API Docs	Swagger UI
